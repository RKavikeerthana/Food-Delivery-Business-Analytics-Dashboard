# 🍔 Food Delivery Business Analytics Dashboard

> Turning food delivery data into actionable business insights with Python and Power BI.

## 📌 About the Project

This project analyzes food delivery data to understand business performance, restaurant efficiency, revenue trends, and order behavior. Python is used for data processing and analysis, while Power BI is used to create an interactive dashboard for visualizing key metrics.

## 🎯 Objectives

- Analyze food delivery order trends.
- Identify top-performing restaurants.
- Monitor revenue and order distribution.
- Evaluate delivery time performance.
- Analyze order cancellations and order statuses.
- Support better business decisions through data visualization.

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| Python | Data analysis |
| Pandas | Data manipulation |
| Matplotlib | Data visualization |
| Power BI | Interactive dashboard |
| CSV | Dataset format |

## 📊 Key Analysis

- **Restaurant Performance** – Compare order counts across restaurants.
- **Revenue Analysis** – Explore revenue generated by restaurant.
- **Monthly Trends** – Track revenue changes over time.
- **Delivery Analysis** – Compare delivery times.
- **Cancellation Analysis** – Identify cancellation patterns.
- **Order Insights** – Understand order statuses and order values.

## 🚀 Getting Started

**Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Food-Delivery-Business-Analytics-Dashboard.git
```

**Install dependencies**

```bash
pip install pandas matplotlib
```

**Run the project**

```bash
python main.py
```

**View the dashboard**

Open `food.pbix` in Power BI Desktop.

## 💡 Business Value

This dashboard helps transform raw food delivery data into meaningful insights that can help businesses evaluate restaurant performance, monitor revenue, improve delivery efficiency, and understand order trends.

# 🍔 Food Delivery Business Analytics Dashboard

An interactive data analytics project exploring food delivery business performance using Python and Power BI.

## 📊 Project Overview
This project analyzes food delivery data to identify business trends, restaurant performance, revenue patterns, delivery efficiency, and cancellation behavior.

## 🎯 Objectives
- Analyze order trends and restaurant performance
- Track revenue and monthly sales patterns
- Understand delivery efficiency
- Analyze cancellation rates and order status
- Generate actionable business insights

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- Data Visualization

## 📈 Analysis Performed
- Orders by restaurant
- Revenue by restaurant
- Monthly revenue trends
- Delivery time comparison
- Cancellation rate analysis
- Order status distribution
- Order value distribution

## 📁 Project Contents
- `food.pbix` – Power BI dashboard
- `orders.csv` – Dataset
- `main.py` – Main execution script
- `data.py` – Data loading
- `data_cleaning.py` – Data preprocessing
- `analysis.py` – Business analysis
- `visualization.py` – Visualization functions
- `outputs/` – Charts and processed data

## 🚀 How to Run
```bash
pip install pandas matplotlib
python main.py
```

Open `food.pbix` in Power BI Desktop to explore the dashboard.
